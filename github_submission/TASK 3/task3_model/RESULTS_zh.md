# 第三问研究结果：固定Pre-LightGBM后的时空调度

## 实际运行范围

最终结果使用336个完成且通过逐请求不变量检查的唯一配置—重复组合；不同配置有意共用随机数，并非336个独立统计样本。跨实验复用相同配置的缓存，不把复用计作新随机重复。主要比较使用完整7335请求、3个固定公共服务扰动重复。需求/故障/延迟/预测敏感性采用1000个固定分层请求，复杂度边界和规划窗口用500个固定分层请求；已完成的完整规模需求2倍及两故障压力实验列在experiment_full_stress.csv。规模基准为100/500/1000/7335，每规模1次运行，不能据此给出普遍扩展性保证。

数据是2025全年三个地区逐小时提供方CO2e快照，合计26280行；生命周期为主、直接CO2e为独立敏感性。没有生成真实回答、质量标签或碳观测。合成RouterBench到达过程仅平移到2025-01-02 UTC，非真实2025业务流量。原PDF未提供，研究问题依据用户所附第三问文字。

## RQ1：空间调度收益及其上限

实际数值见主表和图01。空间差异通过活跃增量、传输和控制开销影响净收益；物理机群始终为6台常开8-GPU DGX，每地区S/L各一台，但各池只准入1个服务槽位，合计48张安装GPU、6个可调度槽位。所有未使用或不可用池仍计整机空闲功率。MPC主情景空闲碳均值41140.351200g，占总量99.7753%；空闲电量固定为250.56kWh。因此即使把大部分推理移到低碳地区，总设施减排也可能很小。不能用活跃部分的减排百分比替代总量减排百分比。

## RQ2：复杂调度与简单贪心

Greedy在当前可用/估计可排队地区按最近可见碳选择，不主动寻找未来低碳小时。MPC优化已经到达的等待请求，可通过在绿色地区排队、避免争抢或短期保留容量改变位置/开始时间。主策略Persistence未来曲线恒定，不能预知未来低碳小时，因此不会有凭空的未来预测收益。收益来源需用逐请求地区、等待和solver日志解释，不归于模型选型变化。

需求和故障数值见aggregate_demand.csv、aggregate_availability.csv；不同情景仍使用同一请求ID、模型、配置容量、种子和12小时观察窗口。故障只关闭新任务准入，已运行任务完成；不可用不意味着断电。高负载容量下降表示外部争用槽位，没有虚构额外任务的耗电。复杂策略在紧约束下可能超时、回退或服务失败，均计入统计。

## 条件结论

完整主实验MPC的平均服务违反率为0.077255%。因此若该值非零，就不能声称当前策略已满足零违反的部署要求，也不能仅凭正碳差宣称复杂策略“值得”。可将本结果作为改进预测、准入、安全余量或业务SLA之前的条件研究。真实碳曲线是历史提供方数据；网络、服务器功率/PUE、容量故障、需求映射和控制增量功率是显式假设；推理时间由事前估计和公共随机数模拟。任何节碳数字均是条件反事实结果，不是实际GPT-4/Mixtral部署减排。

当前结果已经使用新版功率重新优化并在DES执行，不是对旧调度轨迹简单乘系数。功率继承当前Task1配置和task2/runs/experiment：共享1500W/台、8张GPU、每GPU空闲175W、忙碌760W；整机空闲2900W、一个忙碌槽位3485W、PUE1.2。共享/空闲是未实测假设，760W是特定基准配置代理，不是GPT-4/Mixtral整机实测。旧175/250W情景保存在archives/legacy_power_175_250_20261017，不能与本轮数据混合。

所有图表都由已完成实验文件生成。当前版本Task1/Task2和数据准备文件563个SHA256保护项保持不变；旧版保护记录仍在归档。旧数据准备接口21项合成测试继续验证，旧全数据验证器因路径/功率字段已过时而被显式替代，当前冻结路由、保存Pre、训练长度、服务估计及能耗由新源验证程序逐项复查。没有下载生成模型或调用付费LLM。
